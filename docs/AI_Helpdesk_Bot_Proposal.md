## 1. สรุปผู้บริหาร (Executive Summary)

เสนอพัฒนา **AI Chatbot ภายในองค์กร** ที่ตอบคำถาม IT ซ้ำๆ ได้อัตโนมัติผ่าน Lark โดยใช้ข้อมูลจาก SOP และคู่มือที่มีอยู่แล้ว

| | ก่อน | หลัง |
|---|------|------|
| คำถามซ้ำๆ (รหัสผ่าน, เน็ต, ปริ้น) | IT ตอบเอง ทุกครั้ง | Bot ตอบทันที 24/7 |
| เวลาตอบ | 15-60 นาที (รอ IT ว่าง) | < 10 วินาที |
| IT workload | ถูกดึงจากงานหลัก | โฟกัสงาน infrastructure |

**ผลลัพธ์ที่คาดหวัง:** ลด IT ticket ซ้ำๆ 40-60% → ประหยัด ฿44,928/ปี

**ค่าใช้จ่าย: ฿0** (ใช้ server ที่มี + open source ทั้งหมด)

### 5.4 ข้อมูลที่ใช้ (Knowledge Base)

| แหล่ง | เนื้อหา | วิธีดึง |
|--------|---------|---------|
| Lark Wiki | IT SOP, คู่มือ, FAQ | Lark API (sync อัตโนมัติทุกวัน) |
| Lark Docs | นโยบาย, ขั้นตอน | Lark API |
| GLPI | ข้อมูล asset, inventory | GLPI API (มีอยู่แล้ว) |
| ไฟล์ที่มี | คู่มือพนักงาน, IT policy | Upload ครั้งเดียว |

### 5.5 ความสามารถของ Bot

**✅ ตอบได้:**
- วิธี reset password
- วิธีเชื่อมต่อ WiFi / VPN
- วิธีแก้ปัญหา printer
- วิธีใช้ระบบต่างๆ (GLPI, Lark, etc.)
- ข้อมูล IT policy (เบิกอุปกรณ์, ขอสิทธิ์)
- ค้นหา asset จาก GLPI ("เครื่องแผนก QA มีกี่เครื่อง")

**❌ ตอบไม่ได้ (ส่งต่อ IT อัตโนมัติ):**
- ปัญหา hardware ที่ต้องไปดูหน้างาน
- ปัญหา network ระดับ infrastructure
- การขอสิทธิ์พิเศษ (ต้อง approve)
- คำถามที่ไม่มีใน knowledge base

## 6. ความปลอดภัย (Security)

| มาตรการ | รายละเอียด |
|---------|-----------|
| ข้อมูลไม่ออกนอกองค์กร | รัน LLM บน server ภายใน (ไม่ส่งไป cloud) |
| Prompt Injection Protection | ตรวจจับคำสั่งหลอก AI (10+ patterns) |
| PII Filtering | กรองเลขบัตร, เบอร์โทร, email ก่อนส่งให้ AI |
| Rate Limiting | จำกัด 60 คำถาม/นาที/คน (ป้องกัน abuse) |
| Audit Log | บันทึกทุกคำถาม-คำตอบ (ตรวจสอบได้) |
| Access Control | เฉพาะพนักงานในองค์กรเท่านั้น (ผ่าน Lark) |

## 7. แผนดำเนินการ

### Phase 0: Data Audit (วันที่ 1-2)

> ⚡ **ก่อนเริ่มพัฒนา ต้องสำรวจข้อมูลก่อน**

| สิ่งที่ต้องตรวจ | วิธี | ผลลัพธ์ |
|----------------|------|---------|
| SOP ที่มีอยู่ครบไหม? | ดู Lark Wiki | รายการ SOP ที่พร้อมใช้ |
| อัปเดตล่าสุดเมื่อไหร่? | ตรวจ last modified | SOP ที่ต้อง update ก่อน |
| คำถามที่ถามบ่อยจริงๆ | ดู Lark chat history IT group | Top 10 FAQ |
| ข้อมูลที่ **ห้าม** Bot ตอบ | คุยกับผจก. | Blacklist topics |
| ใครเป็น pilot group? | เลือกแผนกที่ถามบ่อย | 1-2 แผนก |

### Phase 1: MVP (สัปดาห์ที่ 1-2)

| วัน | งาน | Deliverable |
|-----|------|-------------|
| 1-2 | ติดตั้ง Ollama + pgvector บน server | ระบบพร้อมรัน |
| 3-4 | รวบรวม SOP/FAQ → Ingest เข้าระบบ | Knowledge base 10-15 หัวข้อ |
| 5 | สร้าง Lark Bot + เชื่อม webhook | Bot ตอบได้ |
| 6-7 | ทดสอบภายใน (IT team ลองถาม) | Bug list |
| 8-10 | ปรับปรุงคำตอบ + เพิ่มข้อมูล | Bot พร้อม pilot |

### Phase 2: Pilot Test (สัปดาห์ที่ 3-4)

| งาน | รายละเอียด |
|------|-----------|
| เปิดให้ pilot group ใช้ | 1-2 แผนก (เช่น QA, AC) |
| เก็บ feedback ทุกวัน | Bot ตอบถูก/ผิดอะไร |
| เพิ่ม GLPI integration | ค้นหา asset ด้วยภาษาธรรมชาติ |
| เพิ่ม Lark Wiki auto-sync | อัปเดตข้อมูลอัตโนมัติทุกวัน |
| ปรับปรุงจาก feedback | เพิ่ม SOP ที่ขาด |

### Phase 3: Production (สัปดาห์ที่ 5-6)

| งาน | รายละเอียด |
|------|-----------|
| เปิดให้ทั้งบริษัทใช้ | ประกาศผ่าน Lark |
| ตั้ง Monitoring dashboard | จำนวนคำถาม, ความพึงพอใจ |
| ตั้ง Escalation → GLPI | Bot ตอบไม่ได้ → สร้าง ticket อัตโนมัติ |
| วัดผล | เปรียบเทียบ ticket ก่อน/หลัง |
