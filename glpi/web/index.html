ทำไมต้องลงทะเบียน?

ฝ่าย IT ต้องรู้ว่าเครื่องคอมพิวเตอร์แต่ละเครื่องอยู่กับใคร เพื่อให้ช่วยเหลือได้รวดเร็วขึ้น

📞
ติดต่อสะดวก — IT รู้ว่าเครื่องนี้อยู่กับใคร ไม่ต้องเสียเวลาตามหา
⚡
แก้ปัญหาเร็วขึ้น — ทีม IT เห็นข้อมูล hardware ของเครื่องคุณล่วงหน้า
🔒
ปลอดภัยมากขึ้น — ถ้าเครื่องหาย IT รู้ได้ทันทีว่าเป็นเครื่องของใคร

2แผนกแผนกที่สังกัด เช่น IT, HR, Operation/PE
3รหัสทรัพย์สิน(ถ้ามี) ดูจากสติ๊กเกอร์ที่ตัวเครื่อง

ขั้นตอนการลงทะเบียน

1
ติดตั้ง GLPI Agentกดปุ่ม "ติดตั้ง GLPI Agent" ด้านล่าง → เปิดไฟล์ที่โหลดมา → กด Yes เมื่อ Windows ถาม → รอจนเสร็จ (ทำครั้งเดียว)
2
เปิดหน้าลงทะเบียนกดปุ่ม "ลงทะเบียนเครื่อง" ด้านล่าง → เปิดไฟล์ที่โหลดมา → เบราว์เซอร์จะเปิดหน้าลงทะเบียนอัตโนมัติ พร้อมชื่อเครื่องของคุณ
3
กรอกข้อมูลพิมพ์ Lark account, เลือกแผนก, กรอกรหัสทรัพย์สิน (ถ้ามี)
4
กดปุ่ม "ลงทะเบียน"ระบบจะบันทึกข้อมูลและแสดงผลสรุปทันที
⚠️ ถ้าเบราว์เซอร์แจ้งว่า "Computer not found" กรุณารอ 5 นาทีแล้วลองใหม่ หรือติดต่อ IT โดยตรง
⬇ ติดตั้ง GLPI Agent ⬇ ลงทะเบียนเครื่อง
